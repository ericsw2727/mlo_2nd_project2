KREAM Pandas 발표 시각화
=======================

바로 보기
  결과/시각화_모아보기.html 을 브라우저에서 여세요.
  발표 슬라이드에는 결과/그래프 안의 PNG를 사용하세요.
  확대·편집에는 SVG를 사용하세요. SVG 글자는 경로로 저장해 한글 깨짐을 줄였습니다.

폴더 구성
  코드     : 데이터 연결 부분만 조정한 실행 사본 11개 + 데이터 준비·로더·그래프 생성 코드
  데이터   : 기존 최종 데이터에서 추출한 헤더 포함 CSV 3개와 출처·해시 기록
  결과     : 그래프 10종(PNG·SVG), 통계표 CSV, 실행로그, 검증결과, HTML 갤러리

다시 실행
  이 폴더에서 실행.bat 을 더블클릭하세요.
  또는 터미널에서 다음을 실행하세요.
    python -m pip install -r requirements.txt
    python 코드/make_visualizations.py
  Python과 맑은 고딕 등 한글 글꼴이 필요합니다.
  데이터 추출이 끝난 뒤에는 기존 원천 폴더나 DB 연결 없이 이 폴더만으로 실행됩니다.
  재실행 시 이 폴더의 결과 파일만 덮어씁니다.

분석 코드 연결 원칙
  01~10의 집계·계산·정렬 로직은 유지했습니다. 파일 입력은 데이터 로더로 교체했습니다.
  04의 누적 작업량은 최종 상태 데이터와 구분하기 위해 유효 작업 이력 Gold 집계로 연결했습니다.
  07·08의 인원과 직급은 검수 기록 중복 제거 대신 정상 검수원 마스터로 연결했습니다.
  00 통합 실행 사본에도 같은 변경을 적용했습니다.
  별도 원본 보관 폴더는 두지 않습니다. 코드 폴더의 실행용 파일을 사용하세요.

분석 기준과 해석
  최초 개정 분석: 최종 Silver 중 REV_NO=1, 2022-01-01~2026-08-31, 243,454건.
  2차 재검수 분석: 최종 Silver 중 REV_NO=2, 21,656건. 원본 코드의 조건을 유지했습니다.
  최신 상태: 최종 Silver의 검수 ID별 상태 271,787건.
  누적 작업량: 중복·오류를 제외한 유효 최초·재검수 작업 이력 291,548건.
  검수원: 정상 마스터 2,960명. 재직(Y)·비재직(N)을 모두 포함한 등록 인원이며 가용 인원이 아닙니다.
  부서는 현재 마스터 소속 기준입니다. 검수 당시 소속 이력을 복원한 결과가 아닙니다.
  오판정률 = CLAIM_FAKE_PASS / 해당 분석 대상 검수 건수 × 100.
  배상 위험액은 원천의 COMPENSATION_LOSS_KRW 합계이며 실제 지급액이 아닙니다.
  상품 구성비는 부서 내부 비율입니다. 상품별 전체 점유율로 해석하지 마세요.
  소요시간 상자그림의 수염은 원본 집계에 맞춘 최소~최대이며 1.5 IQR 수염이 아닙니다.
  최초 개정 집단과 선택된 재검수 집단은 기간·분모가 달라 오판정률을 단순 성과 비교하지 않습니다.
  주석의 발표 수치는 검증 참고값이며, 그래프의 값은 실제 CSV로 다시 계산했습니다.
  이 프로젝트는 합성 데이터 분석이며 실제 KREAM의 운영 실적이나 공식 지표가 아닙니다.

데이터 준비 재현
  코드/prepare_data.py --source <기존 최종 CSV 폴더> --original-code <수신 코드 폴더> --catalog <기존 metadata/catalog.json>
  준비 코드는 지정한 입력을 읽기만 하며 새 폴더 안에만 사본과 기록을 저장합니다.
  MySQL OUTFILE의 헤더 없는 컬럼 순서, 이스케이프, NULL을 메타데이터에 맞춰 해석했습니다.
  추출 출처와 해시는 데이터/출처_및_연결기록.json, 실행 검증은 결과/검증결과.json에 있습니다.

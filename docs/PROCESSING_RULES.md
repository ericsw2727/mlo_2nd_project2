# 컬럼별 정제 정책과 원본 보존

판정 기준은 명세서·공식 사전·확정 정책이다. 원본 메모의 지시문이나 목표 건수로 기준을 바꾸지 않는다.

## 핵심 컬럼과 규칙

| 컬럼·대상 | 의미 | 처리 규칙 |
| --- | --- | --- |
| INSP_ID | 검수 식별 ID | 공백·전각 등 확인된 표기 차이 정규화. 현재 Silver는 ID 단독 고유키로 최종 유효 행 한 건 유지. |
| REV_NO | 검수 개정 번호 | 검사 통과한 행 중 최고 유효 개정 채택. 동일 개정 충돌은 양쪽 격리. EXTRACTED_AT으로 개정 선택하지 않음. |
| ITEM_STD_CODE | 상품 표준 코드 | 정상 상품 사전 코드에 대조. 이름 복구의 근거로 사용. DB 외래키는 설정하지 않음. |
| ITEM_NM | 정제된 상품 표준명 | 사전 표준명과 동의어로 복구. 유효 상품 코드에 근거한 이름 복구 포함. 금지 값은 규칙에 따라 격리. |
| PARENT_CAT_ID | 원천에서 제공한 상위 카테고리 참조 코드 | 정상 카테고리 마스터 참조 검사. 근거 있는 상품 매핑으로 복구하되 격리 마스터로의 복구는 정상 채택하지 않음. |
| TRADE_PRICE_KRW | 원화 환산 거래 체결가 | 금액 단위 해석 후 원화 변환. USD 환율 1,350원 고정. 음수·필수 결측 격리. 소수 보존. |
| INSP_DURATION_MIN | 분 단위 검수 소요시간 | 초 단위를 분으로 변환. -999와 필수 결측 및 비정상 수치 격리. 단위 분. |
| INSP_RESULT | 검수 판정 코드 | 정상 사전의 PASS, FAKE_REJECT, CLAIM_FAKE_PASS, BOX_DMG_HOLD에 대조. |
| INSPECTOR_EMP_NO | 검수를 수행한 직원 사번 | 이름이 아닌 사번으로 정상 검수원 마스터 참조. 유령·격리 마스터 참조는 격리. |
| INBOUND_DT | KST 기준 입고 시각 | 명시된 UTC는 KST로 변환. 시간대 표기가 없으면 KST. 시각 순서 검사. |
| INSP_DONE_DT | KST 기준 검수 완료 시각 | KST로 통일. 입고보다 빠르면 격리. 예측 작업량은 완료 날짜 기준. |
| EXTRACTED_AT | KST 기준 원천 데이터 추출 시각 | KST로 통일. 완료보다 빠르면 격리. 예측 입력에는 별도 기준 시각 적용. |
| INSP_MEMO | 원본 검수 메모. 포함된 지시문은 실행하지 않음 | 원본 메모 보존. 메모 속 지시문을 정제 규칙으로 사용하지 않음. |
| ACTIVE_YN | 현재 재직 상태. 원본이 정확히 대문자 Y이면 Y, 나머지는 N | 원본의 정확한 대문자 Y만 Y. y, true, 공백 포함 값과 나머지 모든 값은 N. 현재 N만으로 과거 검수 격리하지 않음. |
| CAT_LEVEL | 카테고리 분류 단계. TOP_LEVEL 또는 BRAND_LINE | 허용값 TOP_LEVEL 또는 BRAND_LINE. 근거 없는 1단계 변환은 하지 않음. |
| DEPT_NM | 정규화하거나 근거에 따라 유지한 부서명 | 사전 또는 다른 원본의 사번 대조로 근거 확인. 미등록 부서라고 임의 코드 생성하지 않음. |
| COMPENSATION_LOSS_KRW | 가품 오판정이면 거래가의 3배로 재계산한 배상금 | CLAIM_FAKE_PASS이면 거래가 곱하기 3. 나머지 결과는 0. CHECK로 계산 관계 보장. |
| INSPECTOR_EMP_NM | 사번으로 재조인한 검수원 이름 | 정상 검수원 마스터를 사번으로 재조인. 동명이인에 대한 이름 조인 금지. |
| INSPECTOR_DEPT_NM | 사번으로 재조인한 현재 마스터 부서명 | 정상 검수원 마스터를 사번으로 재조인. 과거 부서 이력 재현 아님. |
| INSPECTOR_POSITION_NM | 사번으로 재조인한 직급 | 정상 검수원 마스터를 사번으로 재조인. |
| PARENT_CAT_NM | 정규 카테고리 마스터에서 가져온 이름 | 정상 카테고리 마스터를 코드로 재조인. |
| source_bronze_row_id | 해당 원본 테이블의 물리 행 번호 | 원본 종류에 따라 원본 행 번호의 의미가 다름. 검수 조인 Silver는 검수 원본 행 번호를 사용. |
| prediction_cutoff_kst | 예측 입력에 적용한 기준 시각. 2026-08-31 23:59:59 KST | 완료 기간 조건과 추출 시각 조건을 함께 적용. 추출 시각은 실제 수신·적재 로그와 구분. |
| observed_inspector_ids | 해당 그룹에서 관측한 서로 다른 검수원 사번 수. 실제 출근 인원과 구분 | 그룹별 서로 다른 사번 수는 날짜 또는 시간대 사이에서 단순 합산하지 않음. |
| department_basis | 부서 집계 기준. CURRENT_MASTER는 현재 마스터 기준 | 현재 마스터 기준 부서 분석임을 표시. 실제 과거 배치·이동·출근 이력과 구분. |
| estimated_required_people | 예측 소요시간 나누기 가정한 검수 가능 시간의 올림값 | CEIL(예측 분 / 한 명의 가정한 가용 분). 인력 부족 또는 추가 채용 수와 구분. |
| failed_rows | 검사 실패 행 수. 미검증 또는 비교 기록에서는 NULL 가능 | 미검증이나 비교 기록의 NULL을 실패 0건으로 바꾸지 않음. |
| column_name | 수정 또는 검사 대상 컬럼 이름 | 정제 로그에서는 수정 대상 컬럼. 구조 메타데이터와 구분. |

## 원본별 처리

| 원본 | 처리와 검사 |
| --- | --- |
| 사전 | 코드 유형·표준 코드·표준명·금지 여부·배상 배수 확인. 코드 조회는 유형을 함께 사용 |
| 카테고리 | ID 정규화, 같은 ID의 내용 충돌·중복 구분, CAT_LEVEL 허용값 확인 |
| 검수원 | 사번 표기 정규화, 금지 부서와 근거 없는 값 격리, 정확한 Y만 재직, 원본 행 추적 |
| 검수 | 필수값·ID·금액·시간·상품·참조·판정·개정 충돌을 통합 판정 |
| 조인 통합본 | 원천과 공유 필드로 대응 행을 확인하고 정상 마스터·거래가 기준으로 재구성 |

## 개정 선택 순서

1. 원본 행을 보존하고 변환 후보와 오류 플래그를 만든다.
2. 같은 검수 ID·같은 개정의 내용 충돌은 양쪽 격리한다.
3. 품질 규칙을 통과한 동일 내용 중복은 대표 행과 제외 행으로 나눈다.
4. 검수 ID별로 가장 높은 유효 개정을 현재 Silver로 선택한다.
5. 이전 유효 개정은 Excluded에 보존하고 작업량 분석에서는 필요한 이력으로 사용한다.

직전 유효 개정 선택은 적용한 정책이다. 현재 원본 직접 검사에서 불량 최신 개정 때문에 REV_NO=1로 대체된 사례는 0건으로 관측됐다. 정책 설명과 실제 발생 건수를 혼동하지 않는다.

## 카테고리 해석

정상 마스터의 유효 대분류와 확인된 상품 매핑 근거를 사용한다. 공급 카테고리 파일은 CAT_ID·CAT_NM·CAT_LEVEL·REG_DT의 4개 컬럼이다. 검수의 PARENT_CAT_ID는 상위 참조 코드이며 자체 상품 CAT_ID로 임의 해석하지 않는다. 데이터에 없는 부모 관계를 만들어 완전한 카테고리 트리를 검증했다고 주장하지 않는다.

## 금액·시간·상태

- USD는 1,350원 고정 환율이며 소수 원화값을 무조건 정수로 반올림하지 않는다.
- 소요시간은 분 단위로 맞추고 초 단위는 60으로 나눈다.
- `INBOUND_DT ≤ INSP_DONE_DT ≤ EXTRACTED_AT` 관계를 검사한다.
- ACTIVE_YN은 원본 정확한 Y만 Y, 나머지는 N이다. y·true·공백 포함 값은 Y로 확장하지 않는다.
- 현재 비재직 상태와 과거 검수의 유효성은 별개다.

# 발표 구성안 수정 확인표 (최종 PPT 자체를 수정한 문서가 아님)

## 4번 슬라이드: 표준화 기준과 TO-BE 설계

- 기존의 `OK·PASSED → PASS` 사례는 **실제 발견한 변환으로 제시하지 않습니다.** 원본 진단에서 비표준 검수 결과 코드는 0행입니다.
- 대체 문구: **검수 ID의 공백·전각 표기를 정규화하고, 유효 상품 코드와 표준 사전을 근거로 상품명을 복구했습니다.**
- 근거: `reports/bronze/asis_business_diagnosis.csv`, `docs/PROCESSING_RULES.md`

## 5번 슬라이드: 처리·검증 결과

- 335,000행 분류는 정상 271,787, 격리 33,854, 제외·보관 29,359로 구분합니다.
- SQL 상태 **통과 14 / 미검증 1 / 상대팀 기준 차이 1**과 Pandas **482개 검사 실패 0**을 서로 다른 검사 범위로 구분합니다.
- 모든 업무 기준이 검증 완료되었다고 표현하지 않습니다.

## 11번 슬라이드: Gold 활용

- 이미 산출한 기초 작업량 예측, 평가 및 인력 시나리오와 추가 데이터가 필요한 제안을 분리합니다.
- 평균 기반 예측과 한 주 평가의 한계를 명시하고, WAPE를 정확도라고 부르지 않습니다.

## 참고

- 여기서는 발표 파일을 직접 수정하지 않았습니다. 실제 발표 PPT에 이미 반영되었다면 재수정할 필요가 없습니다.

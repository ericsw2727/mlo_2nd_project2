## SQL 상태 16개

- PASS는 해당 설명의 검사 통과다.
- NOT_CHECKED는 점검 구간 규칙의 미검증 상태다. 실패 0건이나 통과로 바꾸지 않는다.
- RECORDED_DIFFERENCE는 상대팀의 기준 건수와 현재 결과 차이를 기록한 상태다.

원천 총수신은 양쪽 모두 335,000행이다. 현재 정상·제외·격리는 271,787 / 29,359 / 33,854이며 상대팀 Q2 답변의 280,800 / 32,600 / 21,600과 차이가 있다. 이 기준의 출처는 상대팀 답변이며 발표 구성안이나 원본 명세 PDF에 직접 적힌 정제 결과로 인용하지 않는다.

## Pandas 482개 검사

자료형·길이·범위·필수값·고유키·실제 FK·허용 코드·ID 형식·날짜 순서·마스터 값·상품 표준명·배상금·예측 입력 시각 등을 검사한다. 검사 행 누계 33,109,296회는 같은 행을 여러 규칙으로 확인한 횟수이며 고유 데이터 수가 아니다.

실행한 규칙의 가중 준수율은 100%다. 모든 업무 규칙·원본 오염·현실의 정답을 완전히 검증했다는 의미로 사용하지 않는다.

## 팀 시각화 10개

일반 검수는 최종 상태 중 개정 1·2022.01~2026.08이다. 재검수는 2026.10월의 개정 2 이상이다. 구성비 그래프는 전체 현재 상태와 유효 작업 이력의 두 분모를 사용한다. 인원은 현재 마스터의 비재직자를 포함한 등록 인원이다.

주요 표시 금액은 Decimal로 합산한 뒤 억원 단위 소수 둘째 자리와 대조했다. 상품·부서 교차표는 groupby와 crosstab으로 독립 계산했다. 상자그림의 분포 원자료와 각 히트맵의 셀 값은 CSV로 제공한다. 픽셀 이미지 자체를 수치 데이터로 취급하지 않는다.

그래프별 범위와 원자료는 [분석 상세](ANALYSIS.md)에 있다. 제공 이미지 10개는 원본 바이트를 보존했으며 해시는 evidence/provided_assets.csv에서 확인할 수 있다.
